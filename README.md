# ChatApp-POE

## Description
This project is a Java console-based Chat App registration and login system.

## Features
- User registration
- Username validation
- Password complexity validation
- South African cellphone number validation
- User login authentication
- Login status messages
- JUnit 5 testing

## Technologies
- Java 17
- Maven
- JUnit 5
- Git

## Project Structure
- Login.java - Handles validation, registration and login functions.
- Main.java - Runs the console application.
- LoginTest.java - Contains JUnit 5 tests.

## How to Run
Run the Main class from Apache NetBeans.

## Testing
The project includes JUnit 5 tests for username validation, password validation, cellphone validation and login authentication.
